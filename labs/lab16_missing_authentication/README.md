# Lab 16: 重要な機能に認証がない（V8.2 / V13.4）

## 対応する ASVS 要件
- **V8.2.1 (L1)** 機能を使えるのは、その権限を持つ利用者だけに限る
- **V13.4.5 (L2)** 内部向けのドキュメントや監視・管理のエンドポイントを、外に公開しない

## 課題
`exercise.py` の `handle(path, token)` は、小さな Web アプリの入口です。
`/api/me` はログインを確かめていますが、あとから足した運用向けの `/internal/env`（設定の一覧）と `/internal/backup`（データベースの丸ごとの写し）は、ログインを確かめ忘れています。

次のように直してください。

- 「公開してよい道」を `PUBLIC_PATHS` に書き、それ以外はすべてログインを求める（新しく足した道も、既定で守られる）
- ログインしていなければ `Unauthorized`
- `/internal/` で始まる道は、管理者（`role == "admin"`）でなければ `Forbidden`
- 知らない道は `NotFound`

## 実行
```bash
python3 labs/run.py lab16
```
