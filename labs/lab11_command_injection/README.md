# Lab 11: OS コマンドインジェクション（V1.2.5）

## 対応する ASVS 要件
- **V1.2.5 (L1)** OS のコマンドを呼ぶときは、パラメータ化した呼び出しを使い、利用者の入力をシェルに解釈させない

## 課題
`exercise.py` の `count_lines(base_dir, name)` は、置き場所 `base_dir` にあるファイル `name` の行数を `wc -l` で数えて返します。
今は名前を文字列でつなげて `shell=True` で動かしているので、`;` や `$( )` を混ぜた名前で、別のコマンドまで動いてしまいます。

次のように直してください。

- シェルを通さず、`["wc", "-l", "--", name]` のように引数をリストで渡す（`--` の後ろはオプションではなくファイル名として扱われる）
- コマンドが失敗したら（終了コードが 0 以外）`BadInput` を送出する

> ⚠️ 本番では、そもそも OS のコマンドを呼ばずに、言語の機能（Python なら `open()` で数える）で済ませるのがいちばん安全です。

## 実行
```bash
python3 labs/run.py lab11
```
