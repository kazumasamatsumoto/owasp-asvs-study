# Lab 15: コードインジェクション（V1.3.2）

## 対応する ASVS 要件
- **V1.3.2 (L1)** `eval()` など、入力を動的にコードとして実行する機能を使わない。使うなら、入力を検証・サニタイズしてから

## 課題
`exercise.py` の `calc(expr)` は、利用者が入力した計算式（`1 + 2 * 3` など）の答えを返す電卓です。
今は `eval()` で計算しているので、式の代わりに Python のコードを書かれると、そのままサーバーで動きます。

次のように直してください。問題があれば `BadExpr` を送出します。

- `eval()` は使わない。`ast.parse(expr, mode="eval")` で式を木にして、自分で計算する
- 許可するのは、数（int / float）、`+ - * /`、かっこ、先頭の `-` だけ（`**` や名前・関数呼び出し・属性は拒否）
- 100 文字より長い式、文法の誤り、0 での割り算も `BadExpr`
