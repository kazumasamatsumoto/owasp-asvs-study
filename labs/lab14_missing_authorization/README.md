# Lab 14: 認可チェックの欠如（V8.2 / V8.3）

## 対応する ASVS 要件
- **V8.2.1 (L1)** 機能を使えるのは、その権限を持つ利用者だけに限る（機能レベルのアクセス制御）
- **V8.3.1 (L1)** 認可はサーバー側（信頼できる層）で行い、利用者が送ってきた値に頼らない

## 課題
`exercise.py` の `call_admin(session, users, action, params)` は、管理画面の API です（利用者の削除・全員の書き出し）。
今は「ログインしているか」だけを見ているので、ふつうの会員でも管理者の操作ができてしまいます。

次のように直してください。問題があれば `Forbidden` を送出します。

- ログインしていなければ拒否（今のまま）
- セッションの `role` が `"admin"` でなければ拒否（`params` に入った `role` は信じない）
- 知らない `action` は拒否（決めた操作だけを許可する）

python3 labs/run.py lab14
