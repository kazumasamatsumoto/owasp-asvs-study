# Lab 10: パストラバーサル（V5.3）

## 対応する ASVS 要件
- **V5.3.2 (L1)** 利用者が渡したファイル名をそのままパスに使わない。使うなら検証して、決めた置き場所の外に出られないようにする

## 課題
`exercise.py` の `read_document(base_dir, name)` は、資料の置き場所 `base_dir` から `name` のファイルを読んで返します。
今は `name` をそのままつなげているので、`../` や絶対パスで置き場所の外のファイルを読めてしまいます。

次のように直してください。問題があれば `Forbidden` を送出します。

- `name` に NUL 文字が入っている、または絶対パスなら拒否
- `base_dir / name` を `resolve()` した結果が `base_dir` の中に無ければ拒否（`Path.is_relative_to`）
- 置き場所の中に留まる `reports/../manual.txt` のような名前は読んでよい

> ⚠️ 本番では、利用者には ID だけを選ばせ、ファイル名はサーバー側で決めるのがいちばん安全です。

## 実行
```bash
python3 labs/run.py lab10
```
