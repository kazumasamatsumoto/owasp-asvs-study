# Lab 13: 安全でないデシリアライズ（V1.5.2）

## 対応する ASVS 要件
- **V1.5.2 (L2)** 信頼できないデータのデシリアライズでは、型の許可リストなどで安全に処理する。明らかに安全でないデシリアライズの仕組み（Python の `pickle` など）を、信頼できない入力に使わない

## 課題
`exercise.py` の `load_cart(cookie)` は、ブラウザの Cookie に入れたカート（買い物かご）を読み戻す処理です。
今は `pickle` で読み戻しているので、細工した Cookie を送られると、読み戻すだけでサーバーの上で任意のコードが動きます。

次のように直してください。問題があれば `BadCart` を送出します。

- `save_cart` / `load_cart` を JSON に変える（`pickle` は使わない）
- 読み戻した後で形を確かめる：`{"items": [{"id": 文字列, "qty": 1〜99 の整数}, ...]}` だけを受け付ける
- base64 や JSON として読めない値も `BadCart`

> ⚠️ Cookie に入れたデータは利用者が自由に書き換えられます。値段などの大事な情報は、サーバー側に置いてください。

python3 labs/run.py lab13
