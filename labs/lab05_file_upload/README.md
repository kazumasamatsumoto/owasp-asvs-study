# Lab 05: ファイルアップロードと Zip 展開（V5.2 / V5.3）

## 対応する ASVS 要件
- **V5.2.1 (L1)** 処理可能なサイズのファイルだけ受け付ける
- **V5.2.2 (L1)** 拡張子が想定どおりか、かつ中身（マジックバイト等）が拡張子と一致するか検証
- **V5.2.3 (L2)** 圧縮ファイルは展開前に「展開後の合計サイズ」と「ファイル数」の上限をチェック
- **V5.2.5 (L3)** シンボリックリンクを含む圧縮ファイルを拒否
- **V5.3.2 (L1)** ファイルパスにはユーザー指定のファイル名ではなく内部生成の名前を使う（パストラバーサル対策）
- **V5.3.3 (L3)** 展開時にユーザー指定のパス情報を無視する（Zip Slip 対策）

## 課題
`exercise.py` の 2 関数を修正してください。

1. `save_upload(base_dir, filename, data) -> Path`
   - 1 MiB を超えたら `ValueError`
   - 拡張子は `.png` `.jpg` `.jpeg` `.pdf` のみ。マジックバイトも一致すること
   - 保存名はランダムに生成（例: `secrets.token_hex(16) + 拡張子`）。必ず `base_dir` 直下に保存
2. `extract_zip(zip_bytes, dest_dir) -> list[Path]`
   - エントリ数 100 超、展開後合計 10 MiB 超なら展開前に `ValueError`
   - シンボリックリンクのエントリがあれば `ValueError`
   - エントリ名のディレクトリ部分は無視し、`dest_dir` 直下にファイル名だけで展開（`..` や絶対パスは無効化）

## 実行
```bash
python3 labs/run.py lab05
```
