# Lab 12: SSRF（サーバーサイドリクエストフォージェリ）（V1.3.6）

## 対応する ASVS 要件
- **V1.3.6 (L2)** 利用者の入力から作った URL にサーバーが取りに行くときは、プロトコル・ドメイン・パス・ポートの許可リストで確かめる

## 課題
`exercise.py` の `fetch_url(url, resolve, http_get)` は、利用者が渡した URL の中身をサーバーが取りに行く処理です（画像のプレビューなど）。
今は URL をそのまま使っているので、クラウドのメタデータ（`169.254.169.254`）や `localhost` の管理画面など、外からは届かない場所にサーバー経由で届いてしまいます。

この演習ではネットワークを使いません。名前を IP にする `resolve(host)` と、取りに行く `http_get(ip, port, path)` は、テストが作り物を渡します。

次のように直してください。問題があれば `Forbidden` を送出します。

- スキームは `https`、ホストは `ALLOWED_HOSTS`、ポートは指定なしか `443` だけを許可
- `resolve()` で引いた IP が内部の住所（`ipaddress` の `is_global` が偽）なら拒否（許可したホスト名が内部の IP を返す場合に備える）
- 取りに行くときは、確かめた IP を使う（もう一度名前を引かない）
