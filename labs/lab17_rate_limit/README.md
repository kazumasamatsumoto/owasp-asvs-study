# Lab 17: 回数制限がない（総当たり）（V6.3.1 / V2.4.1）

## 対応する ASVS 要件
- **V6.3.1 (L1)** クレデンシャルスタッフィングやパスワードの総当たりを防ぐ仕組みを、設計どおりに実装する
- **V2.4.1 (L2)** 自動化された大量の操作を防ぐ（回数制限など）

## 課題
`exercise.py` の `login(store, user, password, now)` は、何回間違えても試し続けられます。
攻撃者は、よく使われるパスワードを上から順に、当たるまで試せてしまいます。

次のように直してください。

- 同じアカウントで 15 分（`WINDOW` 秒）の間に 5 回（`MAX_FAILURES`）失敗したら、そのアカウントを 15 分ロックする
- ロック中は、正しいパスワードでも `Locked` を送出する（当たったかどうかを教えない）
- ロックが明けたら、また試せる。成功したら失敗の数を 0 に戻す
- パスワードは `hmac.compare_digest` で比べる

> ⚠️ 本番では、アカウントごとの制限に加えて IP ごとの制限・多要素認証・漏洩済みパスワードの拒否を組み合わせます。
