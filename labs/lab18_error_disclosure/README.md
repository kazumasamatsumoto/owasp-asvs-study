# Lab 18: エラーで内部の情報が漏れる（V16.5.1 / V13.4.2）

## 対応する ASVS 要件
- **V16.5.1 (L2)** 想定外のエラーやセキュリティに関わるエラーでは、利用者には汎用的なメッセージだけを返し、スタックトレース・クエリ・秘密の鍵・トークンなどの内部の情報を含めない
- **V13.4.2 (L2)** 本番環境では、デバッグ用の機能や詳しいエラー表示を無効にする

## 課題
`exercise.py` の `handle(order_id, log)` は、注文を 1 件返す API です。
内部でエラーが起きると、エラーの中身（SQL 文・データベースのサーバー名と版）をそのまま利用者に返しています。攻撃者は、わざとエラーを起こして中の作りを調べられます。

次のように直してください（`orders.py` は作り物のデータベースなので編集しません）。

- 想定外のエラーでは、利用者には `{"error": "internal error", "incident": <問い合わせ番号>}` だけを返す（状態コード 500）
- 詳しい中身は、問い合わせ番号と一緒に `log`（リスト）に残す
- 注文が無いときは `404` と `{"error": "not found"}` を返す（入力をそのまま返さない）

## 実行
```bash
python3 labs/run.py lab18
```
